# AURA LUXE — POS & Personal Style Consultation Studio 💄✨
> ระบบบริหารงานขายหน้าร้าน (POS) ควบคู่กับระบบวิเคราะห์ภาพลักษณ์ครบวงจร: Personal Color, รูปทรงหน้า, สรีระ และสไตล์ชุดตามเทศกาล พร้อมแดชบอร์ดสถิติรายวัน/รายเดือน ออกแบบเพื่อ Deploy บน **Vercel** และเชื่อมต่อฐานข้อมูล **Supabase**

---

## 🌟 ฟีเจอร์หลักของระบบ (Key Features)

### 1. 🛍️ ระบบขายหน้าร้าน (POS Terminal)
- **หมวดหมู่สินค้า & บริการ**: แบ่งหมวดหมู่อย่างชัดเจน (บริการวิเคราะห์, คอร์ส/แพ็กเกจสุดคุ้ม, เครื่องสำอางตามโทนสี, เครื่องประดับขับผิว)
- **ระบบค้นหา & กรอง**: ค้นหาชื่อบริการหรือสินค้าได้แบบ Real-time
- **ตะกร้าสินค้า (Cart)**: เพิ่ม/ลดจำนวน คำนวณยอดรวม (Subtotal), ส่วนลด (Discount), ภาษีมูลค่าเพิ่ม (VAT 7%) และยอดสุทธิ (Total)
- **ช่องทางการชำระเงิน**: รองรับ PromptPay QR Code, เงินสด (Cash), บัตรเครดิต และโอนเงิน
- **ใบเสร็จดิจิทัล (Digital Receipt)**: หน้าต่างสรุปรายการพร้อมรหัสออเดอร์ (เช่น `AL-20260930-001`), ชื่อแคชเชียร์, ข้อมูลภาษี, QR Code จำลอง และปุ่ม **พิมพ์ใบเสร็จ (Print)**

### 2. 🎨 วิเคราะห์ Personal Color & โทนแต่งหน้า (Personal Color Studio)
- **แบบทดสอบ Undertone**: ประเมินเส้นเลือดที่ข้อมือ, เครื่องประดับที่ขับผิว, ปฏิกิริยาต่อแสงแดด เพื่อจำแนก Warm Tone หรือ Cool Tone
- **ระบบ 4 ฤดูกาล (4 Seasons & 12 Sub-types)**:
  - 🌸 **Spring (Warm & Bright)**: โทนพีช คอรัล ส้มสดใส แชมเปญโกลด์
  - ❄️ **Summer (Cool & Soft)**: โทนชมพูกลีบกุหลาบ ลาเวนเดอร์ เทาหม่น เงินแพลตตินัม
  - 🍁 **Autumn (Warm & Deep)**: โทนส้มอิฐ เทอร์ราคอตต้า น้ำตาลทอง มัสตาร์ด โรสโกลด์
  - 💎 **Winter (Cool & Vivid)**: โทนแดงทับทิม ไวน์เบอร์กันดี น้ำเงินรอยัลบลู ขาว-ดำ
- **Virtual Color Drape (ทาบผ้าเทียบสี)**:
  - เลเยอร์ผ้าเดรปเสมือนจริงที่เปลี่ยนสีได้ทันทีเมื่อคลิกที่พาเลทสี
  - รองรับการ **อัปโหลดรูปใบหน้าของคุณเอง** เพื่อดูการขับออร่าผิวแบบสดๆ
- **คู่มือการแต่งหน้าเฉพาะบุคคล**:
  - พาเลทสีลิปสติก พร้อมตัวอย่างแถบสี (HEX Swatches)
  - โทนสีบลัชออน และเทคนิคการปัด
  - โทนสีอายแชโดว์
  - อันเดอร์โทนรองพื้น (Yellow / Pink / Neutral)
  - เครื่องประดับที่ช่วยขับผิว (Gold vs Silver)
  - **⚠️ สีที่ควรหลีกเลี่ยง (Worst Colors to Avoid)**

### 3. 💇‍♀️ วิเคราะห์รูปหน้า & ทรงผมที่เข้ากัน (Face Shape Studio)
- **6 รูปทรงหน้ามาตรฐาน**:
  - 🥚 **หน้ารูปไข่ (Oval)**: สัดส่วนสมดุล ทำได้เกือบทุกทรงผม
  - ⚪ **หน้ากลม (Round)**: เน้นทรงผมยาวสไลด์เลเยอร์ Curtain Bangs เพื่อเพิ่มความเรียวยาว
  - 🔲 **หน้าเหลี่ยม (Square)**: เน้นลอนคลื่นนุ่มนวลเพื่อลดทอนความแข็งของขากรรไกร
  - 💖 **รูปหัวใจ (Heart)**: เน้นบ็อบระดับคาง เติมเต็มวอลลุ่มช่วงปลายคาง
  - 🔷 **ทรงเพชร (Diamond)**: สไลด์พรางโหนกแก้มสูง เปิดช่วงหน้าผากและคาง
  - 📏 **หน้ารูปยาว (Oblong)**: หน้าม้าตรงหรือซีทรู เพิ่มวอลลุ่มด้านข้าง
- **คำแนะนำครอบคลุม**: แนะนำทั้งทรงผมผู้หญิง, ทรงผมผู้ชาย, สไตล์หน้าม้า, กรอบแว่นตาที่เข้ากับหน้า และทรงผมที่ควรเลี่ยง
- **เครื่องคิดเลขคำนวณสัดส่วนหน้า**: กรอกความกว้างหน้าผาก โหนกแก้ม กราม และความยาวหน้า

### 4. 👗 วิเคราะห์สรีระ & ทรงเสื้อผ้า (Body Shape Studio)
- **เครื่องคำนวณสัดส่วน B-W-H**: กรอกขนาดรอบอก เอว และสะโพก (นิ้ว) ประมวลผลหาหุ่นทันที
- **5 สรีระหลัก**:
  - ⏳ **นาฬิกาทราย (Hourglass)**: เน้นเดรส Wrap Dress เสื้อเข้ารูปเน้นเอว กางเกงเอวสูง
  - 🍐 **ลูกแพร์ (Pear / Triangle)**: เสื้อเปิดไหล่ แขนพอง ดึงดูดสายตาขึ้นบน กางเกงขากระบอกสีเข้ม
  - 📏 **ทรงกระบอก (Rectangle)**: เสื้อมีระบาย เข็มขัดคาดเอว กระโปรงบานสุ่ม
  - 🔻 **สามเหลี่ยมคว่ำ (Inverted Triangle)**: เสื้อคอวีลึก กางเกงขาบาน Wide-leg เพิ่มวอลลุ่มช่วงล่าง
  - 🍎 **แอปเปิ้ล (Apple / Round)**: เสื้อคอวีทรง Empire ทูนิค เสื้อคลุมตัวยาว โชว์เรียวขา
- **คู่มือแต่งกายครบชุด**: ทรงคอเสื้อ, แขนเสื้อ, กางเกง, กระโปรง, เดรส และข้อควรเลี่ยง

  - 💒 **Wedding Guest**: สวยหรู ถูกกาลเทศะ ไม่แย่งซีนเจ้าสาว

## 🗄️ การตั้งค่า Supabase Database

1. สมัครหรือเข้าสู่ระบบที่ [https://supabase.com](https://supabase.com)
2. สร้าง New Project
3. ไปที่เมนู **SQL Editor** ทางซ้ายมือ
4. คัดลอกเนื้อหาทั้งหมดในไฟล์ [`supabase_schema.sql`](file:///c:/Users/PWK/Desktop/pos/supabase_schema.sql) ไปวางแล้วกด **RUN**
5. ไปที่ **Project Settings** > **API** เพื่อคัดลอก:
   - **Project URL**
   - **anon public API Key**
6. เปิดหน้าระบบ AURA LUXE > ไปที่แท็บ **⚙️ ตั้งค่า & ฐานข้อมูล** > กรอก URL และ Anon Key > กดบันทึก

> 💡 **หมายเหตุ**: หากยังไม่ได้เชื่อมต่อ Supabase ระบบจะทำงานบน **Local Storage** ให้โดยอัตโนมัติ 100% สามารถทดลองใช้งาน เพิ่มสินค้า ทำรายการ และดูสถิติได้ทันที!

## 🚀 การ Deploy ขึ้น Vercel

โปรเจกต์นี้ได้รับการตั้งค่า [`vercel.json`](file:///c:/Users/PWK/Desktop/pos/vercel.json) ให้พร้อมสำหรับการ Deploy แบบ Static Single Page App โดยอัตโนมัติ

### วิธีที่ 1: Deploy ผ่าน GitHub (แนะนำ)
1. นำโค้ดขึ้น GitHub Repository
   ```bash
   git init
   git add .
   git commit -m "feat: Aura Luxe POS & Style Studio"
   git branch -M main
   git remote add origin <YOUR_GITHUB_REPO_URL>
   git push -u origin main
   ```
2. ไปที่ [https://vercel.com](https://vercel.com) > คลิก **Add New...** > **Project**
3. เลือก Repository ที่เพิ่งอัปโหลด
4. คลิก **Deploy** ทันที (Vercel จะสร้าง URL ใช้งานจริงให้อัตโนมัติ เช่น `https://aura-luxe.vercel.app`)

### วิธีที่ 2: Deploy ผ่าน Vercel CLI
```bash
npx vercel
```
ทำตามขั้นตอนบนหน้าจอ แล้วระบบจะขึ้นออนไลน์ทันที!
