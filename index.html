✨ LUXURY POS & IMAGE CONSULTATION STUDIO

AURA LUXE — ระบบบริหารร้านค้า & วิเคราะห์ภาพลักษณ์ครบวงจร

แพลตฟอร์ม POS ยุคใหม่สำหรับธุรกิจความงามและสตูดิโอปรับลุค ผสานศาสตร์การวิเคราะห์ Personal Color 12 Seasons, รูปทรงหน้า & ทรงผม, สรีระหุ่น และ ชุดตามสถานที่ & เทศกาล พร้อมสรุปกราฟสถิติรายวันและรายเดือน เชื่อมต่อฐานข้อมูล Supabase และพร้อม Deploy บน Vercel ทันที

🌟 ข้อมูลคร่าวๆ และฟังก์ชันหลักของระบบ

เลือกใช้งานโมดูลต่างๆ ของ AURA LUXE ได้ทันทีจากรายการด้านล่าง

🛍️
1. ระบบขายหน้าร้าน (POS Terminal)
จัดการแคชเชียร์ขายสินค้าและบริการวิเคราะห์ภาพลักษณ์ ตะกร้าสินค้า คูปองส่วนลด ภาษีมูลค่าเพิ่ม (VAT 7%) รับชำระผ่าน PromptPay QR, เงินสด, บัตรเครดิต พร้อมออกใบเสร็จดิจิทัลพิมพ์ได้
เปิดระบบขาย POS →
🎨
2. วิเคราะห์ Personal Color & แต่งหน้า
แบบทดสอบ Undertone ผิวจริง (Warm vs Cool), ผ้าเดรปเทียบสีเสมือนจริงที่เปลี่ยนสีได้สดๆ (รองรับอัปโหลดรูปตัวเอง), จำแนก 4 Seasons 12 Sub-types พร้อมพาเลทลิปสติก บลัชออน รองพื้น และสีที่ควรเลี่ยง
เริ่มวิเคราะห์สีผิว →
💇‍♀️
3. วิเคราะห์รูปทรงหน้า & ทรงผม
จำแนก 6 รูปทรงหน้า (รูปไข่, กลม, เหลี่ยม, หัวใจ, เพชร, หน้ายาว) แนะนำทรงผมผู้หญิงและผู้ชายที่รับกับโครงหน้า สไตล์หน้าม้า (Curtain Bangs) แว่นตาที่ขับใบหน้า และทรงที่ควรหลีกเลี่ยง
ตรวจรูปหน้า & ทรงผม →
👗
4. วิเคราะห์สรีระ & ทรงเสื้อผ้า
เครื่องคิดเลขคำนวณหุ่นจากสัดส่วน อก-เอว-สะโพก จำแนก 5 สรีระหลัก (นาฬิกาทราย, ลูกแพร์, ทรงกระบอก, สามเหลี่ยมคว่ำ, แอปเปิ้ล) พร้อมคู่มือเลือกเสื้อ คอเสื้อ กางเกง กระโปรง และเดรสพรางหุ่น
คำนวณสรีระ & สไตล์เสื้อผ้า →
🏮
5. ชุดตามสถานที่ & เทศกาลสำคัญ
สไตล์บุ๊คแนะนำชุดที่เหมาะสมสำหรับ คาเฟ่, ทำงาน/สัมภาษณ์, เที่ยวทะเล, งานแต่งงาน, งานกาล่าดินเนอร์ และเทศกาลสงกรานต์, คริสต์มาสปีใหม่, ตรุษจีน, ลอยกระทง, ฮาโลวีน พร้อมแถบสีและเมคอัพที่แมตช์
เปิดดูสไตล์บุ๊ค →
📊
6. แดชบอร์ดกราฟ & สถิติการใช้งาน
กราฟสถิติยอดขายและรายการต่อวัน (Daily) และต่อเดือน (Monthly), กราฟสัดส่วนลูกค้า 4 ฤดูกาล (Donut Chart), ตารางบันทึกกิจกรรมการใช้งานระบบของ Admin/Member พร้อมปุ่มส่งออกข้อมูลเป็น CSV
ดูแดชบอร์ดสถิติ →

📋 สคริปต์ SQL สร้างตารางข้อมูลใน Supabase

คัดลอกคำสั่งในไฟล์ supabase_schema.sql ไปวางใน Supabase SQL Editor แล้วกด Run เพื่อสร้างตารางสินค้า คำสั่งซื้อ และการวิเคราะห์ทันที

-- ตารางที่พร้อมสร้างใน Supabase:
✓ public.profiles (โปรไฟล์สมาชิก และประวัติสี)
✓ public.services_products (รายการสินค้า & บริการ POS)
✓ public.orders & public.order_items (คำสั่งซื้อ & รายการย่อย)
✓ public.consultations (ประวัติการตรวจ Personal Color & สรีระ)
✓ public.usage_logs (บันทึกการใช้งานต่อวันและเดือน)
✓ Row Level Security (RLS) Policies

🚀 วิธี Deploy ขึ้น Vercel (1-Click)

โปรเจกต์นี้ตั้งค่า vercel.json ไว้เรียบร้อยแล้ว รองรับการ Deploy บน Vercel ทันที:

  1. นำโฟลเดอร์นี้ขึ้น GitHub Repository (เช่น git init && git push)
  2. ไปที่ vercel.com แล้วกด Add New Project
  3. เลือก Repository ของคุณ แล้วกด Deploy ได้ทันที ไม่ต้องตั้งค่า Build Command เพิ่มเติม
